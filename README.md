# Learning-log
AI发展太快了，想不出来未来想从事的方向，只好每天记录所学内容，让自己获得一点学习成就感

## 日记记录格式

从 2026 年 9 月 10 日起，`Diary/` 中的每日日记统一按以下顺序记录：

1. **今日计划**：放在最上面，用待办清单记录任务，注明固定时间和建议安排。
2. **学习内容与完成情况**：按当天实际反馈补充学了什么、完成了什么、还有什么卡点；未反馈的任务保持待完成，不把计划写成已完成。
3. **睡前总结**：记录当天收获、未完成事项及原因，以及明天最重要的一件事。

详细学习笔记继续放在 `Learning-Diary/`，需要时从当天日记链接过去。
